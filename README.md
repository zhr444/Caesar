# 🔐 Шифровальщик текста

**Онлайн-шифровальщик с двумя классическими алгоритмами — прямо в браузере.**

Один HTML-файл. Внутри — шифр Цезаря с поддержкой русского и английского алфавитов и XOR-шифрование с base64-упаковкой. Тёмный интерфейс, две вкладки, мгновенное копирование результата в буфер обмена. Никаких фреймворков, сборщиков и внешних зависимостей.

---

## 🎮 Возможности

- **Два шифра:**
  - 🏛️ **Шифр Цезаря** — сдвиг букв на любое целое число. Поддерживает **русский** и **английский** алфавиты одновременно, включая букву `Ё`. Регистр сохраняется, спецсимволы и цифры не трогаются.
  - 🔀 **XOR-шифрование** — побайтовый XOR с произвольным ключом. Результат кодируется в **base64**, чтобы его можно было безопасно копировать и передавать.
- **Шифрование и дешифрование** — обе операции в один клик.
- **UTF-8 из коробки** — корректно работает с русским, эмодзи и любыми юникод-символами.
- **Две вкладки** — переключение между Цезарем и XOR без перезагрузки.
- **Копирование результата** — кнопка `📋 Копировать` с современным `navigator.clipboard` и фолбэком через `execCommand`.
- **Toast-уведомления** — всплывающие сообщения «Скопировано», «Введи текст», «Не удалось расшифровать» и т.д.
- **Горячая клавиша `Ctrl+Enter`** — запускает шифрование на активной вкладке.
- **Тёмная тема** — градиентный фон `#1e1e2f → #2d1b4e`, акцентный фиолетовый `#7c5cff`.
- **Валидация ввода** — предупреждения, если текст пустой, сдвиг не число или base64-строка битая.

```
git clone <репозиторий>
cd text-encryptor
```

Открой `index.html` двойным кликом в браузере.

> ⚠️ Копирование через `navigator.clipboard` работает только в защищённом контексте (`https://` или `localhost`). При открытии через `file://` автоматически сработает fallback через `execCommand('copy')` — он работает везде.

## 🕹️ Как пользоваться

### Шифр Цезаря

1. Открой вкладку **«Шифр Цезаря»**.
2. Введи текст в поле «Исходный текст» (русский, английский или смешанный).
3. Укажи **сдвиг** — целое число. Положительное — вправо (A→D при сдвиге 3), отрицательное — влево.
4. Нажми **«🔒 Зашифровать»** или **«🔓 Расшифровать»**.
5. Результат появится в блоке «Результат». Скопируй кнопкой `📋 Копировать`.

**Пример:**
- Текст: `Привет, World!`
- Сдвиг: `3`
- Зашифровано: `Тулези, Zruog!`
- Расшифровано обратно при сдвиге `-3` (или `-3` через кнопку «Расшифровать»).

### XOR-шифрование

1. Открой вкладку **«XOR»**.
2. Введи текст (для шифрования) **или** base64-строку (для расшифровки).
3. Укажи **ключ** — любую непустую строку. Чем длиннее ключ, тем лучше.
4. Нажми **«🔒 Зашифровать»** — получишь base64-строку.
5. Чтобы расшифровать — вставь base64-строку в то же поле и нажми **«🔓 Расшифровать»** с тем же ключом.

**Пример:**
- Текст: `Секрет`
- Ключ: `secret`
- Зашифровано (base64): `HBsaHxY=` (пример; результат зависит от ключа)
- Расшифровка с тем же ключом вернёт `Секрет`.

> 🔑 **Важно:** без правильного ключа расшифровка невозможна. XOR — симметричный шифр.

| `xorCipher(text, key)` | XOR-шифрование с base64-упаковкой |
| `xorDecipher(encoded, key)` | Расшифровка XOR из base64 |

| `copyText(text)` | Копирование в буфер с fallback |
| Обработчики `click` | Привязка кнопок к функциям шифрования |

### Константы алфавитов

```js
const RU_UPPER = "АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ";
const RU_LOWER = RU_UPPER.toLowerCase();
const EN_UPPER = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
const EN_LOWER = EN_UPPER.toLowerCase();
const ALPHABETS = [[RU_UPPER, RU_LOWER], [EN_UPPER, EN_LOWER]];
```

Функция `caesarShift` проходит по каждому символу и проверяет, есть ли он в одном из алфавитов. Если есть — сдвигает внутри этого алфавита, сохраняя регистр. Если нет (пробел, цифра, знак препинания, эмодзи) — оставляет как есть.

## 🔍 Как работают алгоритмы

### Шифр Цезаря

Классический сдвиговый шифр: каждая буква заменяется на другую, стоящую в алфавите через `shift` позиций.

```
A + 3 → D
Я - 1 → Ю
```

Поддерживается **два независимых алфавита** (русский и английский), и символы каждого сдвигаются внутри своего алфавита. Это значит, что смешанный текст типа `Hello, Мир!` корректно шифруется и расшифровывается: `Khoor, Плу!`.

Отрицательный сдвиг используется для дешифрования — достаточно передать `-shift`.

### XOR-шифрование

Побайтовый XOR исходного текста с ключом:

```
cipher[i] = plain[i] ^ key[i % key.length]
```

Свойства:
- **Симметрично** — то же действие с тем же ключом возвращает исходный текст.
- **Требует ключ** — без него расшифровка даёт мусор.
- **Не является стойким шифром** — при известном или повторяющемся ключе легко взламывается частотным анализом. Годится для учебных целей и лёгкой обфускации, но **не для реальной защиты секретов**.

Результат кодируется в **base64**, чтобы его можно было скопировать в текстовом виде, отправить в мессенджере или сохранить в файл.

## 🐛 Известные особенности

- `navigator.clipboard.writeText` работает только в защищённом контексте. Через `file://` автоматически используется `document.execCommand('copy')` — старый, но рабочий.
- XOR с коротким ключом (1–2 символа) даёт слабый шифр — используй ключи от 8 символов.
- Шифр Цезаря — учебный, не для реальной защиты. Не используй его для паролей.
- Emoji и иероглифы в XOR-шифровании кодируются как несколько байт UTF-8 и корректно возвращаются при расшифровке благодаря `TextEncoder`/`TextDecoder`.

## ⚠️ Безопасность

**Этот инструмент не предназначен для защиты реальных секретов.**

- Шифр Цезаря взламывается перебором 33 (RU) или 26 (EN) сдвигов за миллисекунды.
- XOR с коротким или повторяющимся ключом уязвим к частотному анализу.
- Никакие данные не отправляются на сервер — всё считается локально в браузере.

Для реальной криптографии используй проверенные библиотеки: `Web Crypto API` (`crypto.subtle`), `libsodium.js`, `TweetNaCl.js`.
